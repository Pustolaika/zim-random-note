# Zim Random Note

A small plugin for [Zim](https://zim-wiki.org/) that opens a random non-empty page from the current notebook.

## Installation

Copy the `randomnote` directory to the Zim user plugins directory
Restart Zim and enable Random Note in:
Edit → Preferences → Plugins
The command is available in:
Tools → Random Note
Requirements
- Zim 0.77.x
- Python 3
